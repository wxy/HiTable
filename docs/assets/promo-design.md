# Chromatic Order

以规则网格表达秩序，以四边伸出的统计带表达即时反馈。选区与统计共享同一套坐标，四角手柄落在真实交点上。构图的识别力来自数据向四周展开的关系，每条线都精确对齐。

配色取自产品现有的绿色主题：浅绿用于数据，主绿用于统计，深绿用于十字高亮；文字使用对应的深色或白色。深绿色画布承托清晰的浅色表格，让浮层在平面上形成明确层次。质感依靠细线、留白和色阶，避免斜置截图、拟物厚度和装饰性阴影。

HiTable 是唯一的大号文字。品牌采用 Instrument Sans Bold，数字采用 Geist Mono，使字形与列宽保持稳定。细致处理每一个数字的基线、间距和边界；没有依赖单一语言的宣传句，技术符号和示例数字承担视觉说明。

两种尺寸分别组织布局。小图保留品牌与一个完整统计图形，在缩小一半后仍有明确轮廓；大图让品牌与图形各自获得呼吸空间。精细的边距和克制的色块共同建立完成度，不靠增加图案填满空白。

图形是一张品牌示意表，不冒充真实网页截图。九个输入为 12/18/24、28/34/16、20/26/22，行和为 54/78/68，列和为 60/78/62；四边展示求和，内侧四角可辨识。实际界面另由每种语言的三张原生截图呈现。所有数字、边线和手柄都须在最终尺寸与半尺寸下检查。
