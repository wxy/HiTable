# Immediate Grid

画面以一片稳定的深绿承托清晰的表格。留白使视线先停在简短的产品承诺，再落入真实数字与四边统计的秩序。版面的精度来自边距、基线和格线之间仔细校准的关系。

颜色保持克制：深绿构成安静的底，白字给出明确的信息层级，浅绿与主绿保留产品本来的识别力。质感依靠平整的色块与精细的边界，不增加立体厚度、材质噪声或装饰光效。

字形是一种结构。中文保持清楚、有分量的系统无衬线；英文与品牌沿用 Instrument Sans。两种语言各自重新安排字宽与换行，使它们拥有相同的视觉重量。细致处理标题与辅助文字之间的节奏，不把长文章标题塞进小画面。

真实统计浮层是唯一的图形主体。全部格子、金额、算法与手柄来自已经验证的演示录屏，不绘制假界面。图像在构图中保留四边统计的完整关系，让熟悉产品的人辨认出它，也让初次看到的人理解“在表格旁边得到结果”。

横幅题图与视频缩略图共享同一组视觉元素，但分别安排纵向间距。逐项检查缩小后的标题、边界和主图，保留足够呼吸空间。最终交付中英文各一张 1920×816 题图和一张 1920×1080 视频缩略图；前者服务文章，后者可作为 YouTube 上传缩略图。

算法覆盖修订：题图与缩略图明确标出“15 种统计”，并举出中位数、标准差和四分位数。真实浮层改用平均值、最大值、求和、中位数四种不同的边缘算法；视频菜单显示全部已启用的 15 项，演示滚动并切换到标准差。图片和录屏均来自未修改的 0.2.2 扩展，不把编辑文案画成产品控件。
