## 技术验证和复现方法

最终四片均为 1920×1080、H.264、yuv420p、30/1fps。45s 版本各 1350 帧、45.000 秒；15s 版本各 450 帧、15.000 秒。对四支最终文件重新完整解码，退出码均为 0、错误输出为空。

```sh
ffprobe -v error -show_streams -show_format -of json <video.mp4>
ffmpeg -hide_banner -v error -i <video.mp4> -f null -
ffmpeg -v error -i <video.mp4> -vf 'select=eq(n\,120)' -frames:v 1 <temporary-frame.png>
# 在 media 目录校验六个最终媒体文件：
shasum -a 256 -c SHA256SUMS.txt
```
