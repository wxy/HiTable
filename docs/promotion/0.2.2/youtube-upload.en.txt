Title
HiTable — Web table statistics without leaving the page

Description
Looking at a web table and only need a quick sum or average? Copying the data can be awkward, and opening a spreadsheet adds extra steps for a small calculation.

HiTable lets you stay on the page, drag across cells and see statistics on all four sides. Choose from 15 statistics, including Median, Standard Deviation, Quartiles, Skewness and Kurtosis. Each edge can use a different calculation; scroll the menu to switch, resize with corner handles and copy the data when needed.

Table processing stays local. No account is needed. This video uses fixed sample data from the built-in demo, with English UI and visible captions. It includes an opening cover and light instrumental accompaniment; visible captions also make the demonstration understandable with the sound off.
