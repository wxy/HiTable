# HiTable v0.2.2 — Selection & themes / 选区与主题

## What's New

- Choose statistics by their localized names from menus at the four outer corners.
- Resize a selection with four data-corner handles. Copy confirmation shows its row and column count; nonnumeric cells are greyed out.
- Use 11 designed colour families with light and dark palettes. Automatic follows the page background, using Neutral Graphite for white, grey and beige pages; fixed themes retain their colour family while adapting to light and dark pages.
- Try 11 background families and a dark toggle on the demo page. Updated store screenshots cover all 10 supported page languages, plus a separate global English set.

## Fixes & Engineering

- Display, statistics, resizing and copying use the same table snapshot captured when selection starts, even if the source page changes its data.
- Activation gives HiTable control of table selection gestures; deactivation restores the page's own interactions. Ordinary clicks and tiny pointer movements do not open the overlay.
- Thin grid and hover lines preserve cell geometry. Resize handles retain the grab offset; clicking their outer edges no longer expands the range.
- Anomaly tooltips retain the explanation alongside the original value.

## Deployment Notes

- Load the extracted extension ZIP, or use the packaged ZIP for Chrome Web Store submission. This plain JavaScript extension has no compilation step.
- No new permissions, dependencies or data migration. Existing saved theme choices retain their colour family.
- GitHub availability and Chrome Web Store rollout are separate. Final store review submission is handled by the maintainer.

## Verification

- Tests: 15 final-archive browser scenarios passed in Chrome 157.0.8103.39, including real clipboard operations, Romanian currency formats, snapshot consistency, toolbar activation and page-event restoration. The palette scenario covers all 22 fixed light/dark palettes; help was checked in 10 locales.
- Builds: all 30 archive files match the release source; JavaScript syntax, JSON, version consistency and local page resource references passed. No compilation is required.
- Assets: 33 real 1280×800 screenshots, three per language plus a separate global English group. Hong Kong page text uses the Hong Kong catalog; Chrome's native extension UI falls back to Taiwan Traditional Chinese.
- Details and acceptance limits: [release verification](https://github.com/wxy/HiTable/blob/v0.2.2/docs/verification/2026-11-11-v0.2.2-release.md).

## 新增功能

- 在外围四角的菜单中，按本地化名称选择统计算法。
- 拖动数据选区四角手柄调整范围；复制后提示行列数量，非数值单元格灰显。
- 提供 11 套设计配色及各自的明暗方案。自动模式按网页背景选色，白、灰、米黄页面使用中性石墨；固定主题保留色系，同时适配网页明暗。
- 演示页可切换 11 个背景色系及深色背景。商店截图覆盖现有 10 种页面语言，并提供独立的全球英文组。

## 修复与工程改进

- 显示、统计、选区调整和复制统一使用开始拖选时的表格快照，避免网页改值导致结果不一致。
- 激活后由 HiTable 接管表格选择手势，停用后恢复网页交互；普通点击和轻微抖动不再弹出浮层。
- 网格与悬停细线不改变单元格尺寸；拖动保留抓取偏移，点击手柄外沿不再意外扩大选区。
- 异常提示保留原因说明和原始值。

## 部署说明

- 解压扩展 ZIP 后可直接加载，也可使用 ZIP 提交 Chrome 商店审核。项目为原生 JavaScript，无需编译。
- 没有新增权限、依赖或数据迁移，已有主题选择保留原色系。
- GitHub 发布与商店上线分开进行，最终商店提审由维护者操作。
