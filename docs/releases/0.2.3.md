# HiTable v0.2.3 — Copy tables as HTML and Markdown / HTML 与 Markdown 表格复制

## What's New

- Copy selected cells with Ctrl+C (⌘C on Mac) as TSV plain text and an HTML table together. The receiving application chooses the clipboard format it supports.
- Copy Markdown plain text with Ctrl+X (⌘X on Mac), without cutting the source table. Press either shortcut twice quickly to include all four sides of statistics.
- Selections without a table header receive an empty Markdown header so every selected data row is preserved.

## Fixes & Engineering

- Preserve missing cells as empty fields when copying irregular tables, including selections whose first header row has gaps.
- Escape literal Markdown characters, including tildes, so source text is preserved rather than interpreted as formatting.
- Improve narrow layouts on the settings, demo and help pages; keep each algorithm control paired with its explanation.
- Update help in all ten supported languages. Editable fields retain their normal copy and cut behavior.

## Deployment Notes

- Upload `hitable-0.2.3-store.zip` to the existing Chrome Web Store item. This plain JavaScript extension requires no compilation.
- No new extension permissions, dependencies or data migration. Reuse the existing store screenshots, promotional artwork and videos.
- GitHub release and Chrome Web Store review are separate; the maintainer performs the final store submission.

## Verification

- Feature checks: real Chrome extension and system clipboard tests cover TSV/HTML/Markdown, single and double shortcuts, statistics, Markdown parsing, native rich-text/textarea paste and editable-field cut behavior. Targeted fixes also cover missing cells and literal tildes.
- Layout checks: settings at 390/620/1280px and demo/help at 390/1280px, including the narrow settings control/explanation pairing.
- Final ZIP: 13 focused checks passed in Chrome 157.0.8103.52, including actual rich-text paste and all ten help-page locales. Package checks and the exact archive hash are recorded in the [0.2.3 release verification](https://github.com/wxy/HiTable/blob/master/docs/verification/2026-11-14-v0.2.3-release.md).
- Real Word/Excel, third-party editor filtering and Windows/Edge paste behavior remain unverified; native rich-text paste does not establish compatibility with those applications.

## 新增功能

- Ctrl+C（Mac：⌘C）同时复制选区的 TSV 纯文本和 HTML 表格，由接收应用选择支持的剪贴板格式。
- Ctrl+X（Mac：⌘X）复制 Markdown 纯文本，不剪切网页源表格。任一快捷键快速连续按两次，即可包含四边统计结果。
- 没有表头的选区自动补充空的 Markdown 表头，保留全部选中数据行。

## 修复与工程改进

- 不规则表格中的缺失单元格保留为空字段，包括首行表头缺格的情况。
- 转义波浪号等 Markdown 字面符号，避免原文被误解释为格式。
- 改善设置、演示和帮助页的窄屏布局，保持算法控件与说明正确配对。
- 同步十种语言的帮助说明；输入框及可编辑内容保留原生复制和剪切行为。

## 部署说明

- 将 `hitable-0.2.3-store.zip` 上传至现有 Chrome 商店条目。项目为原生 JavaScript，无需编译。
- 没有新增扩展权限、依赖或数据迁移；沿用现有商店截图、宣传图及视频。
- GitHub 发布与 Chrome 商店审核分开进行，最终商店提交由维护者操作。
