HiTable: 웹 페이지 테이블 데이터 즉시 분석

페이지를 떠나지 않고, 데이터를 복사하지 않고, Excel 없이 웹 페이지 테이블에서 데이터를 즉시 분석하세요.

HiTable은 브라우저에서 직접 HTML 테이블에 대한 즉각적인 통계 계산을 수행할 수 있는 강력한 브라우저 확장 프로그램입니다. 셀을 드래그하여 선택하면 네 면에 통계가 표시됩니다 — 더 이상 기본 계산을 위해 테이블을 Excel로 복사할 필요가 없습니다.

=== FEATURES ===

테이블 지원:
• 표준 HTML 테이블 — 병합된 셀(rowspan/colspan)이 있는 복잡한 테이블 포함
• 중첩 테이블 — 테이블 안의 테이블을 자동으로 하나의 통합 그리드로 평면화
• Div 기반 테이블 — 클래스 패턴과 기하학적 분석으로 감지된 CSS Grid / Flexbox 레이아웃
• ARIA 그리드 — 시맨틱 마커로 감지된 role="grid" 또는 role="table" 요소

15가지 통계 알고리즘 (4개 그룹):
• 기본: Count, Sum, Average, Minimum, Maximum, Range
• 고급: Median, Standard Deviation, Variance, Mode
• 분위수: Q1 (25%), Q3 (75%), Interquartile Range
• 분포: Skewness, Kurtosis

조건부 서식 및 이상 탐지:
• 3단계 탐지: 선택 영역 전체, 각 열 내, 각 행 내
• 이상값(>2× 표준편차)을 느린 펄스 애니메이션으로 강조
• 마우스를 올리면 각 이상값의 이유와 범위 확인
• 설정에서 켜기/끄기 전환

데이터 무결성 검사:
잠재적으로 조작된 데이터를 발견하는 6가지 테스트:
• Benford's Law — 첫 자리 분포 분석
• Last Digit Analysis — 불균등 분포 감지(인간 편향)
• Rounding Preference — 과도한 0/5 끝자리 경고
• Duplicate Detection — 비정상적으로 빈번한 값
• Ratio Anomaly — 거의 일정한 열 간 비율
• Monotonic Sequence — 지나치게 선형적인 정렬 패턴

숫자 형식 인식:
• 통화 기호: $, €, £, ¥, ₹, ₽, HK$, NT$
• 단위 접미사: K (×1,000), W/万 (×10,000), M (×1,000,000), 亿 (×1억), B (×10억)
• 전각 숫자 정규화 (１２３ → 123)
• 통계 결과는 통화 접두사와 단위 접미사를 자동으로 상속

내장 데모 및 도움말 페이지:
• 모든 기능을 즉시 사용해 볼 수 있는 7개의 샘플 테이블
• 모든 기능을 포괄하는 종합 도움말, 9개 언어로 제공

=== HOW TO USE ===

1. HiTable 아이콘을 클릭하여 활성화 (아이콘이 녹색으로 변경)
2. 테이블에서 셀을 드래그하여 선택
3. 네 면에 통계 표시 — 모서리를 클릭하여 알고리즘 전환
4. Ctrl+C로 셀 복사; 두 번 누르면 전체 오버레이 복사
5. Shift+좌측 상단 클릭으로 전체 테이블 선택
6. Esc로 지우기

확장 프로그램 아이콘 우클릭 → 설정에서 색상, 알고리즘, 활성화 모드를 사용자 지정.

=== PRIVACY ===

HiTable은 사용자 데이터를 수집하지 않습니다. 모든 처리는 로컬에서 이루어집니다. 네트워크 요청이 발생하지 않습니다.
