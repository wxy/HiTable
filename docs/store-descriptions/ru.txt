HiTable: Мгновенный анализ данных веб-таблиц

Анализируйте данные мгновенно в таблицах на веб-страницах, не покидая страницу, не копируя данные, без Excel.

HiTable — это мощное браузерное расширение, позволяющее выполнять мгновенные статистические вычисления непосредственно в HTML-таблицах прямо в браузере. Выделяйте ячейки перетаскиванием и смотрите статистику со всех четырёх сторон — больше не нужно копировать таблицы в Excel для базовых вычислений.

=== ВОЗМОЖНОСТИ ===

Поддержка таблиц:
• Стандартные HTML-таблицы — включая сложные с объединёнными ячейками (rowspan/colspan)
• Вложенные таблицы — таблицы внутри таблиц, автоматически сводящиеся в единую сетку
• Таблицы на основе div — CSS Grid / Flexbox-макеты, определяемые по шаблонам классов и геометрическому анализу
• ARIA-сетки — элементы с role="grid" или role="table", определяемые по семантическим маркерам

15 статистических алгоритмов (4 группы):
• Базовые: Count, Sum, Average, Minimum, Maximum, Range
• Продвинутые: Median, Standard Deviation, Variance, Mode
• Квантили: Q1 (25%), Q3 (75%), Interquartile Range
• Распределение: Skewness, Kurtosis

Условное форматирование и обнаружение аномалий:
• Трёхуровневое обнаружение: по всей выборке, внутри каждого столбца, внутри каждой строки
• Выбросы (>2× стандартного отклонения) выделяются медленной пульсирующей анимацией
• Наведите курсор, чтобы увидеть причину и область каждой аномалии
• Включение/выключение в настройках

Проверки целостности данных:
Шесть тестов для выявления потенциально сфабрикованных данных:
• Benford's Law — анализ распределения первых цифр
• Last Digit Analysis — выявляет неравномерные распределения (человеческая предвзятость)
• Rounding Preference — отмечает чрезмерное количество окончаний на 0/5
• Duplicate Detection — необычно частые значения
• Ratio Anomaly — почти постоянные соотношения между столбцами
• Monotonic Sequence — чрезмерно линейные отсортированные шаблоны

Распознавание числовых форматов:
• Символы валют: $, €, £, ¥, ₹, ₽, HK$, NT$
• Румынские и молдавские форматы: 1.234,56 и 1 234,56; RON, MDL и leu/lei до или после числа
• Суффиксы величин: K (×1 000), W/万 (×10 000), M (×1 000 000), 亿 (×100M), B (×1B)
• Нормализация полноширинных цифр (１２３ → 123)
• Результаты сохраняют десятичный формат, положение валюты и суффикс величины, если они одинаковы в столбце или строке
• Для неоднозначных значений вроде 1,234 выберите формат чисел в настройках
• Конвертация валют не выполняется

Встроенные демо и справочные страницы:
• 8 примеров таблиц для немедленного тестирования всех функций
• Исчерпывающая справка по всем функциям, доступная на 10 языках

Выделение и темы:
• 11 цветовых тем, включая нейтральный графит; автоматический подбор под фон страницы и светлые/тёмные варианты фиксированных тем
• Изменение выделения четырьмя угловыми маркерами; нечисловые ячейки отображаются серым
• Подтверждение копирования с числом строк и столбцов

При включённом HiTable выделением таблицы управляет расширение. Нажмите значок ещё раз, чтобы вернуть действия страницы. Отображение, расчёты и копирование используют один снимок данных; новое выделение обновляет его.

=== ИСПОЛЬЗОВАНИЕ ===

1. Нажмите на значок HiTable для активации (значок станет зелёным)
2. Перетаскивайте для выбора ячеек в любой таблице
3. Статистика с четырёх сторон — выберите алгоритм по переведённому названию в угловом меню
4. Ctrl+C для копирования ячеек; двойное нажатие для копирования всего оверлея
5. Shift+клик в левом верхнем углу для выбора всей таблицы
6. Esc для очистки

Щёлкните правой кнопкой мыши по значку расширения → Настройки для изменения цветов, алгоритмов и режима активации.

=== КОНФИДЕНЦИАЛЬНОСТЬ ===

HiTable НЕ собирает пользовательские данные. Вся обработка выполняется локально. Сетевые запросы не выполняются.
