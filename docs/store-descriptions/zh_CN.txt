HiTable：网页表格数据即时分析

无需离开网页、无需复制数据、不用打开 Excel，即可在网页的表格上进行各种统计分析。

HiTable 是一款强大的浏览器扩展，让您可以直接在浏览器中对 HTML 表格进行即时、原位的统计计算。拖拽选中单元格，即可在四边看到统计结果——无需再将表格复制到 Excel 中进行基本计算。

=== 功能 ===

表格支持：
• 标准 HTML 表格——包括带有合并单元格（rowspan/colspan）的复杂表格
• 嵌套表格——表格中的表格，自动展平为统一网格
• Div 表格——通过 CSS 类名模式和几何分析检测 CSS Grid / Flexbox 布局
• ARIA 网格——通过语义标记检测带有 role="grid" 或 role="table" 的元素

15 种统计算法（4 组）：
• 基础统计：CNT（计数）、SUM（求和）、AVG（平均值）、MIN（最小值）、MAX（最大值）、RNG（极差）
• 高级统计：MED（中位数）、STD（标准差）、VAR（方差）、MOD（众数）
• 分位数统计：Q1（下四分位）、Q3（上四分位）、IQR（四分位距）
• 分布统计：SKW（偏度）、KUR（峰度）

条件格式化与异常检测：
• 三重范围检测：整个选区、每列内、每行内
• 异常值（偏离均值 2 倍标准差以上）以主题色慢脉冲动画高亮
• 悬停可查看每个异常的原因（全局/列/行）和具体偏离数值
• 可在配置页面开关

数据完整性检测：
六项统计检测帮助发现潜在人工编造数据：
• 本福特定律（Benford's Law）——首位数字分布分析
• 末位数字分析（Last Digit）——检测不均匀分布（人的随机感缺陷）
• 取整偏好（Rounding）——标记过多的 0/5 结尾
• 重复值检测（Duplicate）——异常频繁出现的值
• 比例异常（Ratio）——接近常数的跨列比例
• 单调序列（Monotonic）——过于线性的排序模式
结果以 ⚠ 指示器显示在浮层下方，问题单元格有彩色边框标记。

数字格式识别：
• 货币符号：$、€、£、¥、₹、₽、HK$、NT$
• 罗马尼亚及摩尔多瓦数字格式：1.234,56、1 234,56；支持数字前后的 RON、MDL 和 leu/lei
• 数量级后缀：K（千）、W/万（万）、M（百万）、亿、万亿、B（十亿）
• 全角数字归一化（１２３ → 123）
• 统计结果保留所在列/行一致的小数格式、货币位置和数量级后缀
• 遇到 1,234 等歧义数值，可在配置中指定逗号小数或句点小数
• 不进行汇率换算
• 列类型（整数/小数/货币/百分比）显示在提示中

内置演示与帮助页面：
• 8 张示例表格，安装后即可体验所有功能
• 完整帮助文档覆盖所有功能，支持 10 种语言

选区与主题：
• 11 套设计配色，包含中性石墨；可根据网页背景自动选色，固定主题同样适配明暗背景
• 拖动选区四角手柄调整范围；非数值单元格灰显
• 复制后显示成功提示及行列数量

激活后由 HiTable 接管表格选择，再次点击图标可恢复网页原有操作。显示、统计和复制共用同一份数据快照，清除后重新拖选可刷新数据。

=== 使用方法 ===

1. 点击 HiTable 图标激活（图标变为绿色）
2. 拖拽选中任意表格中的单元格
3. 统计结果显示在四边——打开外围角落菜单，按本地化名称选择算法
4. Ctrl+C（Mac：⌘C）同时复制 TSV 纯文本和 HTML 表格；Ctrl+X（⌘X）复制 Markdown，不剪切网页数据。任一快捷键快速连续按两次，包含统计结果。
5. 按住 Shift 点击左上角单元格即可选中整个表格
6. 按 Esc 键清除选择

右键点击扩展图标 → 配置，可自定义颜色、算法和激活模式。

=== 隐私 ===

HiTable 不会收集任何用户数据。所有处理均在本地完成，不产生任何网络请求。
