HiTable：網頁表格數據即時分析

無需離開頁面、無需複製數據、無需 Excel，即可即時分析網頁上的表格數據。

HiTable 是一款功能強大的瀏覽器擴充套件，讓您可以直接在瀏覽器中對 HTML 表格進行即時、原位的統計計算。拖曳選取儲存格，即可在四邊看到統計結果——無需再將表格複製到 Excel 中進行基本計算。

=== 功能 ===

表格支援：
• 標準 HTML 表格——包括帶有合併儲存格（rowspan/colspan）的複雜表格
• 巢狀表格——表格中的表格，自動展平為統一網格
• 基於 Div 的表格——透過類別名稱模式和幾何分析檢測 CSS Grid / Flexbox 佈局
• ARIA 網格——透過語意標記檢測帶有 role="grid" 或 role="table" 的元素

15 種統計算法（4 組）：
• 基礎：CNT 計數、SUM 總和、AVG 平均值、MIN 最小值、MAX 最大值、RNG 範圍
• 進階：MED 中位數、STD 標準差、VAR 變異數、MOD 眾數
• 分位數：Q1 第一四分位數 (25%)、Q3 第三四分位數 (75%)、IQR 四分位距
• 分佈：SKW 偏度、KUR 峰度

條件格式化與異常檢測：
• 三種檢測範圍：跨選區、每欄內、每列內
• 異常值（>2× 標準差）以緩慢脈衝動畫醒目提示
• 懸停查看每個異常的原因和範圍
• 可在設定中開啟/關閉

數據完整性檢查：
六種檢測潛在偽造數據的測試：
• 本福特定律 (Benford's Law)——首位數字分佈分析
• 末位數字分析 (Last Digit Analysis)——檢測不均勻分佈（人為偏差）
• 捨入偏好 (Rounding Preference)——標記過多的 0/5 結尾
• 重複檢測 (Duplicate Detection)——異常頻繁出現的值
• 比例異常 (Ratio Anomaly)——接近常數的跨欄比例
• 單調序列 (Monotonic Sequence)——過於線性的排序模式

數字格式識別：
• 貨幣符號：$, €, £, ¥, ₹, ₽, HK$, NT$
• 羅馬尼亞及摩爾多瓦數字格式：1.234,56、1 234,56；支援數字前後的 RON、MDL 和 leu/lei
• 量級後綴：K (×1,000), W/萬 (×10,000), M (×1,000,000), 億 (×100M), B (×1B)
• 全形數字規範化（１２３ → 123）
• 統計結果保留欄/列中一致的小數格式、貨幣位置和量級後綴
• 遇到 1,234 等歧義數值，可在設定中指定逗號小數或句點小數
• 不進行匯率換算

內置示範與說明頁面：
• 8 個範例表格，可立即試用所有功能
• 全面的輔助說明文件，涵蓋所有功能，支援 10 種語言

選取範圍與主題：
• 11 套設計配色，包含中性石墨；可依網頁背景自動選色，固定主題同樣適應明暗背景
• 拖曳選取範圍四角控制點調整範圍；非數值儲存格灰顯
• 複製後顯示成功提示及列欄數量

啟用後由 HiTable 接管表格選取，再按一下圖示可恢復網頁原有操作。顯示、統計及複製共用同一份資料快照，清除後重新拖曳選取即可更新資料。

=== 使用方法 ===

1. 按一下 HiTable 圖示啟用（圖示變為綠色）
2. 拖曳選取任意表格中的儲存格
3. 統計結果顯示在四邊——開啟外圍角落選單，依本地化名稱選擇演算法
4. Ctrl+C（Mac：⌘C）同時複製 TSV 純文字和 HTML 表格；Ctrl+X（⌘X）複製 Markdown，不剪下網頁資料。快速連按任一快捷鍵兩次，即可包含統計結果。
5. Shift+按一下左上角選取整個表格
6. Esc 清除

在擴充套件圖示上按右鍵 → 設定，自訂顏色、算法和啟用模式。

=== 隱私 ===

HiTable 不會收集任何使用者數據。所有處理均在本地完成，不會產生任何網路請求。
