## 原因与像素定位

基线实际读取：frame border 为 1px，NW/NE/SW/SE 手柄相对数据区边界分别为 (+1,+1)、(-1,+1)、(+1,-1)、(-1,-1) CSS px。相邻统计格的 inset 网格线与 frame 的 top/left border 各画在一侧，形成双线。

移除 frame border 后，还需处理表格绘制取整。DPR 2 截图显示：几何顶部 449.5px 对应的实际线覆盖 449..450px；右边界 775.71875px 的线覆盖 775..776px。最终手柄中心按 `Math.round(edge)-0.5` 定位，frame 宽高由四条绘线中心求得。它与内容尺寸解耦，不改变原网格或缓存尺寸。调整预览采用同一规则，只有虚线 outline，不使用 border。

最终示例：源数据区域 left=419、top=449.5、right=775.71875、bottom=585.5；可见线中心为 left=418.5、top=449.5、right=775.5、bottom=585.5。四个手柄相对可见线中心的误差均为 **0px**。

## 重复执行与范围

工具安装在系统独立临时目录，使用系统 Chrome，按[前一报告的 CDP 方法](2026-11-11-designed-themes.md)加载扩展。执行入口形式为 `node "$HITABLE_PALETTE_FIX_DIR/tools/verify.cjs"`；针对性过滤只运行 handles／1px grid／flat styling／resize／small viewport／visual inspection／error 场景；DPR 1 入口为同目录 dpr1.cjs。旧色板比较明确读取 `e3a3d2711f69c689d600a1bd36c835b1d8e9e381:scripts/themes.js`。

- 对齐输入：demo-financial，rows[1].cells[1] 到 rows[4].cells[4]，中心拖动 8 步后移出。读取数据区包围边界，比较手柄中心与取整后线中心。像素检查用第一数据格左右中点／顶边中点附近的横纵像素，DPR 1、2 分别检查 1、2 个网格像素；像素位于文字 padding 区，无文字覆盖。
- 四角输入：初始 rows[1].cells[1] 到 rows[5].cells[6]；SE/NW/NE/SW 分别拖至浮层数据零起算 [2,3]、[1,1]、[1,3]、[2,1]。Esc 在松手前取消；键盘聚焦 SE 后按左键。窄视口使用 demo-regional 的首列三行缩为两行。
- 自动背景：依次设置 body.style.background 为 #fff、#808080、#ededed、#f5f5dc、#faf7ef、#fff2cc、#f5e6c8、#10171e、#fff0f5、#e0efff、#fff59d、#103c34；表格另设粉色干扰。每次 Esc 后重选，比较预设主色。
- 色板／菜单：配置页真实 radio 逐一切换 11 套主题，在财务表比较三层实际计算样式与数值对比；菜单 color-mix 由浏览器 canvas 解析。十语设置／帮助分别用 locale URL 验证。
