# 中性石墨及深色页面配色验证

日期：2026-11-11。基线：`9dfb667d3f2015f48dce2ba48d45b9cd7380ec0e`。替换 PR #63 的暖石墨，继续保留 PR，不合并、不发布，版本仍为 0.2.1。

## 行为与审查范围

| Before | After | Why |
| --- | --- | --- |
| 白／灰／米黄页面使用偏棕的暖石墨 | 使用已确认的纯灰阶中性石墨 | 补齐黑白主题，与中性底色协调 |
| 深色中性页面也使用同一套浅色 | 自动模式使用设计好的深色变体，包含菜单、灰显和网格 | 避免整块浅底刺眼，同时保留高亮辨识度 |
| 设置、帮助和 README 使用旧名称 | 十语名称与说明、英文 HTML 回退、双语 README 同步 | 明确自动／固定的选择规则 |

两套色板均为静态设计，未增加反色计算。自动模式沿用已有 html/body CSS 背景及 RGB/RGBA 渐变代表色识别；选中中性石墨后，相对亮度低于 0.18 使用深色变体。显式白色页面不会因系统或浏览器工具栏为暗色而变暗。透明背景的画布依据网页声明的 CSS color-scheme 及系统偏好确定，随后再叠加网页实际背景。

手动选择中性石墨始终为已确认的浅色版；其他固定主题也保持原配色。自动选择彩色主题时同样不反转。深色变体属于同一主题，不新增第十二套色块。保存键仍为 `#746b5e`，旧暖石墨选择直接显示新中性石墨，无需迁移设置。设置页自动模式预览仍使用浅色版。

| 角色 | 浅色背景／文字 | 深色背景／文字 | 文字对比度（浅／深） |
| --- | --- | --- | --- |
| 数据 | #e1e1e1 / #242424 | #303030 / #f3f3f3 | 11.87 / 11.89:1 |
| 统计 | #686868 / #ffffff | #686868 / #ffffff | 5.57 / 5.57:1 |
| 高亮 | #1c1c1c / #ffffff | #e1e1e1 / #242424 | 17.04 / 11.87:1 |
| 非数值 | #d2d2d2 / #484848 | #3b3b3b / #b0b0b0 | 6.05 / 5.17:1 |

深色菜单为 #252525／#f3f3f3，缩写为 #bdbdbd；高亮采用浅灰时，菜单当前项仍用独立的亮色文字配深底。网格使用 25% 白色，浅色和彩色主题保留原 65% 白色。所有描线仍为 inset shadow，不参与布局。原十套彩色色板逐字段与基线比较完全相同；本轮未改几何坐标、事件、统计、复制或配置持久化逻辑。

## 实际验证

环境：macOS arm64，系统 Chrome **157.0.8103.39**，Playwright **1.65.0**。独立临时 profile，真实加载仓库根目录扩展，访问 `pages/demo.html`、`config.html`、`help.html`。viewport 1500×1100，DPR 2。使用真实鼠标、键盘、chrome.storage.sync 和剪贴板，无 Chrome API mock，未读取日常浏览器 profile。

完成 **52 个浏览器检查场景**。完整一轮 48 项通过，另外 4 项暴露了测试脚本假定错误：扩展浮层跟随浏览器中文，本地化结果不应硬编码为英文 Sum；table 直接子节点含 colgroup，tr:nth-child(4) 实际对应较前一行，缩放目标应使用 tr:nth-of-type(4)。修正测试输入／断言后，仅复验这 4 项及错误收集，**5 项全部通过**。产品代码未因这些脚本错误再次修改，不重复累计场景数量。更早的脚本试跑因默认自动设置尚未写入 storage 而等待超时，已改为对已选中的 radio 不重复等待保存，不将其误报为产品失败。
