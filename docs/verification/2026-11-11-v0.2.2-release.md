### 复现方式

1. 将正式 ZIP 解压到系统临时目录，用全新 Chrome profile 加载该目录。CLI 自动化可临时安装 `playwright@1.65.0`，使用系统 Chrome，`ignoreDefaultArgs: ['--disable-extensions', 'about:blank']`、`args: ['--enable-unsafe-extension-debugging']`，浏览器级 CDP `Extensions.loadUnpacked`。
2. 表中索引均为 DOM table.rows / cells，从 0 开始；按中心拖动 8 步。选区结构通过 `.HiTableDataCell` 所在行数和每行格数核对。复制使用真实 ⌘C 和 clipboard.readText，允许临时上下文的 clipboard-read/write。
3. HTTP 输入：一个 `lang="ro"` 的 3×2 table，首列 A/B/C，次列 `1.234,56 RON` / `200,44 RON` / `-35,00 RON`；td 为 1px border、20px padding、150px min-width；table margin 150px。table 上分别注册 pointerdown/click 计数。通过 Node http 或 Python 临时 localhost 服务加载，浏览器级 CDP `Extensions.triggerAction` 触发真实启停。
4. 快照检查在第一格 pointerdown 后用页面脚本把其原文改为 `9.999,00 RON`，再移动至末格、松手；统计、显示、复制应保持旧值。下次重新拖选可读到新值。
5. 固定主题在真实 config 页逐一勾选 name=boxColor 的 11 个色值，切换 demoDarkBackground，核对 `--hitable-surface` 与 `HiTableThemes` 对应设计值。帮助用 `pages/help.html?locale=<locale>`。
