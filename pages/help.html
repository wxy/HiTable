HiTable Help

Instant analysis of web page table data — without leaving the page

Basic Usage
  1. Click the HiTable icon in your browser toolbar to activate it on the current page.
  2. Drag your mouse across table cells to select a range of data.
  3. Statistics appear on four sides of the selection: top, right, bottom, left.
  4. Click any corner to cycle through available algorithms for that edge.
  5. Press Esc to clear the selection. Press Ctrl+C to copy data.
Supported Table Types
  • Standard HTML <table> elements — including complex ones with merged cells (rowspan/colspan).
  • Nested Tables inside tables — HiTable recursively flattens them into one unified grid.
  • Div Grid CSS Grid / Flexbox tables (div-based) — detected by CSS class patterns and geometric analysis.
  • ARIA Elements with role="grid" or role="table" — detected via semantic markers.
Available Statistics (15 algorithms)
  • Basic: CNT (Count), SUM (Sum), AVG (Average), MIN (Minimum), MAX (Maximum), RNG (Range)
  • Advanced: MED (Median), STD (Standard Deviation), VAR (Variance), MOD (Mode)
  • Quantile: Q1 (25th percentile), Q3 (75th percentile), IQR (Interquartile Range)
  • Distribution: SKW (Skewness), KUR (Kurtosis)
Conditional Formatting & Anomaly Detection
  • When you select a data range, HiTable automatically checks for anomalous values.
  • An anomaly is a value that deviates from the mean by more than 2× standard deviation.
  • Detection runs at three levels: across the entire selection, within each column, and within each row.
  • Anomalous cells are highlighted with a slow pulsing animation in your chosen theme color.
  • Hover over an anomalous cell to see why it was flagged and at which level.
  • You can toggle this feature on/off in the configuration page.
Data Integrity Checks
  • Benford's Law: Checks if the first-digit distribution follows natural patterns. Deviations may indicate fabricated data.
  • Last Digit Analysis: Detects uneven last-digit distribution — humans tend to avoid certain digits when inventing numbers.
  • Rounding Preference: Flags when too many values end in 0 or 5 (common in manually filled data).
  • Duplicate Detection: Identifies values that appear unusually often — possible copy-paste.
  • Ratio Anomaly: Detects when two columns have a near-constant ratio — may be formula-generated.
  • Monotonic Sequence: Checks if sorted values are too linear — possible auto-fill pattern.
  • Results appear as a ⚠ indicator below the overlay. Hover to see details. Problematic cells are marked with colored outlines.
Number Format Recognition
  • Currency symbols ($, €, £, ¥, ₹, ₽) are automatically detected and stripped for calculation.
  • Magnitude suffixes are recognized: K (×1,000), W/万 (×10,000), M (×1,000,000), B (×1,000,000,000).
  • Percentages are detected and converted: "12.5%" becomes 0.125 for calculation.
  • Negative numbers are supported.
  • Statistical results inherit the currency prefix and magnitude suffix of the source data when consistent across the column/row.
  • Column types (integer, decimal, currency, percentage) are shown in tooltips.
Configuration

Right-click the extension icon and select "Config", or go to the extension options page. You can customize:

  • Activation Mode: Manual (click to activate per tab) or Auto (activate on specific domains).
  • Theme Color: Choose from 10 colors for the selection and overlay.
  • Enabled Algorithms: Select which statistics appear in the corner cycling.
  • Default Algorithms: Set the default statistic for each edge of the overlay.
  • Conditional Formatting: Toggle anomaly highlighting on/off.
Keyboard Shortcuts
  • Esc — Clear selection and close overlay
  • Ctrl + C — Copy selected cell data (double-press to copy entire overlay)
  • Shift + click — Select entire row
  • Click the four corners of the overlay to cycle through statistics.
